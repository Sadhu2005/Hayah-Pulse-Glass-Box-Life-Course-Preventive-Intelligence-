## 1. Definition of Done (Prototype)

Hayah-Pulse prototype is **done** when all boxes below are checked, the app runs locally on synthetic data only, and a 90-second walkthrough can be recorded.

---

## 2. Step 1 — Synthetic cohort

Spec: [v0.5-synthetic-cohort-and-data-model.md](./v0.5-synthetic-cohort-and-data-model.md)

- [ ] Generator script exists and uses `seed=42`
- [ ] 500 residents + 150 households written to `data/synthetic/`
- [ ] Required columns present; cohort mix within tolerance
- [ ] Small-cell demo slice exists (`n < 10`)
- [ ] Disclaimer: synthetic only

---

## 3. Step 2 — Risk / uncertainty / routing engine

Spec: [v0.6-risk-engine-spec.md](./v0.6-risk-engine-spec.md)

- [ ] Care-gap rules implemented
- [ ] Calibrated GradientBoosting model trains and scores all residents
- [ ] SHAP/rule hybrid top 3–5 reasons per flagged resident
- [ ] Uncertainty gate routes sparse records to Baseline Wellness Onboarding
- [ ] Pathway router emits Well-Child / IFHAS / Genetic / Onboarding tracks
- [ ] `engine_outputs.json` (+ CSV) saved
- [ ] Clinical firewall string on clinician-bound records

## 7. Demo script (90 seconds)

| Time | Action | Say |
| --- | --- | --- |
| 0:00–0:25 | Open Clinician Portal; pick overdue pediatric or cardiometabolic adult | “Glass-box flag: pathway + top reasons + confidence—not a black box.” |
| 0:25–0:55 | Switch to Citizen Simulator; toggle AR/EN; show modality + opt-out | “Families see why, what data was used, and choose how to engage.” |
| 0:55–1:30 | Open Fairness Monitor; point to funnel + suppressed cell | “Equity and privacy: small cells masked, outcomes tracked.” |
