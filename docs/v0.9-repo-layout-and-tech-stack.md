| --- | --- |
| Data & ML | Python 3.11+ · `pandas` · `numpy` · `scikit-learn` · `shap` |

| UI | React · Vite · TypeScript · Tailwind CSS |
| Engagement previews | LLM API with guardrails; template fallback |
| Package managers | `pip` / `uv` for Python; `npm` or `pnpm` for frontend |

## 3. Environment variables

`.env.example`:

```
# Optional — bilingual message generation
LLM_API_KEY=
LLM_MODEL=

# API
HAYAH_API_HOST=127.0.0.1
HAYAH_API_PORT=8000

# Paths
SYNTHETIC_DATA_DIR=data/synthetic
```

Never commit real API keys. LLM is optional; templates must work offline.

## 4. Scripts (developer UX)

| Command (illustrative) | Purpose |
| --- | --- |
| `python backend/scripts/generate_synthetic_cohort.py` | Build Step 1 |
| `python backend/scripts/run_engine.py` | Build Step 2 |
| `python backend/scripts/run_evaluation.py` | Build Step 4 |
| `uvicorn app.main:app --app-dir backend --reload` | Serve API |
| `npm run dev` (in `frontend/`) | Serve UI |

Root `README.md` should document these once code exists.

## 5. API sketch (minimum)

| Method | Path | Returns |
| --- | --- | --- |
| GET | `/api/v1/health` | ok |
| GET | `/api/v1/residents` | list summary |
| GET | `/api/v1/residents/{id}` | resident + engine output |
| GET | `/api/v1/metrics/evaluation` | evaluation report |
| GET | `/api/v1/metrics/fairness` | funnel + parity (suppressed) |

## 6. Git ignore essentials

- `.env`
- `node_modules/`
- `__pycache__/`, `.venv/`
- model binaries if large (`*.joblib` optional keep small)
- OS junk

Synthetic CSVs **may** be committed for demo portability (they are fake). Prefer committing them for judges to clone-and-run.
