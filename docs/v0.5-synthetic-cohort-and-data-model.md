## 1. Goal

- **500** synthetic residents
- **150** households
- **Zero** real patient data


## 2. Cohort mix (targets)

| Segment | Approx share | Notes |
| --- | --- | --- |
| Infants / toddlers (Well-Child track) | ~25% | Ages 0–5; milestone/visit fields populated |
| Children / adolescents | ~15% | Ages 6–17; Well-Child continuum |
| Young adults (18+ IFHAS baseline) | ~20% | First IFHAS eligibility / baseline |
| Middle-aged multi-factorial cardiometabolic | ~20% | Family hx, HbA1c/BP trends |
| Elders | ~10% | Higher visit history, IFHAS focus |
| Newly arrived / sparse-record residents | ~10% | Short EHR history; uncertainty demos |

Households should mix pediatric + adult members where useful for **household bundling** demos (~40% of households have ≥1 child and ≥1 adult).

## 3. Resident schema (required columns)

| Column | Type | Description |
| --- | --- | --- |
| `resident_id` | string | Unique synthetic ID (`R-0001` …) |
| `display_name` | string | Synthetic given name (culturally mixed) |
| `age` | int | Years (0–90) |
| `sex` | enum | `female` / `male` |
| `district` | string | Abu Dhabi district / area label (synthetic) |
| `household_id` | string | Link to household (`HH-0001` …) |
| `ehr_months_history` | int | Months of longitudinal EHR available |
| `last_well_child_or_ifhas_date` | date ISO | Last relevant preventive visit date |

| `hba1c_trend` | float | Synthetic trajectory slope (negative/flat/positive) |
| `bp_trend` | float | Synthetic BP trajectory slope |
| `weight_for_length_percentile_delta` | float | Pediatric growth drift (null for adults) |
| `family_history_flag` | bool | First-degree relevant family history |
| `consented_genomic_tier` | enum/null | `actionable` / `informational` / `none` / null |
| `preferred_language` | enum | `ar` / `en` / `ur` / `tl` |

## 5. Generation rules

1. Use a fixed random seed (`seed=42`) for reproducibility.
2. Reference “today” date stored in `meta.json` as `reference_date`.
3. **Sparse newcomers:** force `ehr_months_history < 6` and `consented_genomic_tier` in `{none, null}` for most of that segment (feeds uncertainty gate).
4. **Overdue Well-Child:** for a subset of peds, set `milestone_overdue_days > 30`.
5. **Overdue IFHAS:** for a subset of adults 18+, set `ifhas_overdue_days > 0` (and often &gt; 30).
6. **Compounding risk demos:** ensure ≥30 residents combine family history + adverse trend + care gap.
7. **Small-cell demos:** include at least one rare district/segment combo with `n < 10` for suppression tests.
8. Languages: majority `ar`/`en`; minority `ur`/`tl`.
9. `outreach_consent_status`: mostly `opt_in`; include some `opt_out` for UI toggle demos.
